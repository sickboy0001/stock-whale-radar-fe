### 1. 銘柄詳細情報（yfinance連携）の表示案

銘柄のファンダメンタルズ情報を yfinance (Yahoo Finance) から取得して表示するセクションを追加します。これにより、大量保有者の動向だけでなく、現在の株価指標に基づいた分析が可能になります。

---

### 2. 表示項目

| 項目 | 説明 | 例 |
| :--- | :--- | :--- |
| **株価 (Price)** | 現在の値 (または終値) | ¥4,500 |
| **時価総額 (Market Cap)** | 企業の規模 | 1.2兆円 |
| **PER (Forward)** | 収益性指標 | 15.4x |
| **PBR** | 資産価値指標 | 1.2x |
| **配当利回り** | 株主還元 | 3.2% |
| **52週レンジ** | 過去1年の価格幅 | ¥3,200 - ¥4,800 |

---

### 3. フロントエンド実装イメージ (`src/components/pages/stockholders.tsx`)

既存の銘柄ヘッダーの下に、カード形式でクイックスタッツを表示します。

```tsx
<div className="grid grid-cols-2 md:grid-cols-4 gap-4 mb-6">
  <Card>
    <CardContent className="pt-6">
      <div className="text-sm text-muted-foreground">時価総額</div>
      <div className="text-2xl font-bold">¥1.2T</div>
    </CardContent>
  </Card>
  <Card>
    <CardContent className="pt-6">
      <div className="text-sm text-muted-foreground">PER / PBR</div>
      <div className="text-2xl font-bold">15.4x / 1.2x</div>
    </CardContent>
  </Card>
  {/* ...他の項目 */}
</div>
```

---

### 4. 期待される効果

1.  **投資判断の迅速化**: 大量保有報告が出た際、その銘柄が現在割安なのか割高なのかを同一画面で判断できます。
2.  **文脈の提供**: 保有者が買い増している理由（低PBRなど）を推察しやすくなります。
