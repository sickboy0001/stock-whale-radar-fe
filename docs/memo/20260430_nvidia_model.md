NVIDIA NIMの無料枠（40 RPM：毎分40リクエスト）を活用して、RooCodeなどのコーディングエージェントで利用するのに適した「コスト不要かつ高性能」なモデルを紹介します。

現在Qwen2.5やGeminiをお使いとのことですが、NIMでは**さらに大規模なモデルや最新の推論モデル**が無料で開放されています。

---

## 1. コーディングに最適な推奨モデル（2026年時点）

NIMのカタログには非常に多くのモデルがありますが、RooCodeのような「コードの修正・生成・ファイル操作」を伴うエージェントには、以下のモデルが特に強力です。

### 最優先：推論能力と精度のバランス
*   **DeepSeek-R1 (およびその蒸留版)**
    *   **特徴:** 複雑なロジックの実装やデバッグに非常に強い「推論モデル」です。RooCodeで「なぜこの修正が必要か」を考えさせながら実行させるのに最適です。
    *   **NIM ID:** `deepseek-ai/deepseek-r1` (または `deepseek-r1-distill-llama-70b`)
*   **Llama-3.3-Nemotron-70B-Instruct**
    *   **特徴:** NVIDIAがLlama 3.1をベースに独自にカスタマイズしたモデル。特に指示への忠実度と推論性能が高く、コーディング能力ではGPT-4oクラスに匹敵するベンチマークを叩き出しています。
    *   **NIM ID:** `nvidia/llama-3.1-nemotron-70b-instruct`

### 大規模プロジェクト・高度な論理思考用
*   **GLM-5 / GLM-5.1**
    *   **特徴:** エージェント的な動作（Tool Callingや長文推論）に特化した強力なモデルです。複雑なリファクタリングや依存関係の解決に適しています。
    *   **NIM ID:** `z-ai/glm-5`
*   **Qwen3-Coder (最新版)**
    *   **特徴:** 現在お使いのQwen2.5の後継。NIMではさらにパラメータ数の多い版が提供されており、コード生成の正確性が向上しています。
    *   **NIM ID:** `qwen/qwen3-coder-480b-instruct` (※カタログにより変動あり)

## 2. 比較と使い分け

用途に合わせてRooCodeの設定を切り替えるのが効率的です。

| モデル名 | 得意分野 | RooCodeでの役割 |
| :--- | :--- | :--- |
| **DeepSeek-R1** | 難解なバグの特定・論理思考 | **Planner / Architect** (設計・デバッグ) |
| **Nemotron 70B** | 高精度な指示理解・汎用実装 | **Main Coder** (標準的な開発作業) |
| **Mistral Large 3** | 高速・多言語・安定性 | **Fast Response** (クイックな修正) |

## 3. RooCodeでの設定ヒント

NIMは**OpenAI互換API**を提供しているため、RooCodeの「OpenAI Compatible」設定から以下のように入力するだけで利用可能です。

*   **Base URL:** `[https://integrate.api.nvidia.com/v1](https://integrate.api.nvidia.com/v1)`
*   **API Key:** `nvapi-xxxxxxxxxxxx` (NIMで生成したもの)
*   **Model ID:** 上記のIDをコピー

### 運用のコツ
1.  **レート制限:** 無料枠は毎分40リクエストまでです。RooCodeが連続でファイル読み込みを行うと制限に引っかかることがありますが、数秒待てば回復します。
2.  **クレジット:** 2026年現在のNIM無料枠は「クレジット消費制」から「レート制限（RPM）制」に移行しており、開発・プロトタイプ用途であれば実質無制限で利用可能です。

まずは **`nvidia/llama-3.1-nemotron-70b-instruct`** を試してみてください。Qwen2.5よりも指示の理解が深く、RooCodeの挙動がよりスマートになるはずです。
