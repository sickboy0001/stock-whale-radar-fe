URL:src\app\daily_status\page.tsx

## 1. 画面概要
本画面は `import_daily_status` テーブルのデータを可視化し、日次および月次のデータ取り込み進捗を管理・監視するための画面である。

## 3. 各項目の仕様・ロジック

### A. 年間表示エリア
* **対象年選択**: `target_date` の年部分をフィルタリング。デフォルトはシステム日付の年。
* **月別カード（集計ロジック）**:
    * **済み日**: `status = 'completed'` のレコード数
    * **対象日**: その月の暦どおりの日数
    * **プログレスバー**: (済み日 ÷ 対象日) × 100

### B. 日別詳細エリア（連動仕様）
* **表示トリガー**: 上部の「月別カード」または「詳細」リンクをクリックした際、対象月のデータを抽出して表示。
* **ステータス表示区分**:
    * `completed` → 完了（緑色など）
    * `failed` → 失敗（赤色など）
    * `processing` → 実行中（青色/点滅など）
    * `pending` → 未処理（グレー）
* **進捗率**: `success_count` / `target_docs_count` をパーセント表示。

## 4. テーブル項目とのマッピング

| 画面表示項目 | 対応DBカラム | 備考 |
| :--- | :--- | :--- |
| 日付 | `target_date` | YYYY-MM-DD 形式 |
| ステータス | `status` | 文言表示（日本語化を推奨） |
| 済み件数 | `success_count` | - |
| 対象件数 | `target_docs_count` | - |
| 開始時刻 | `last_run_start_at` | 実行中・完了時のみ表示 |
| 終了時刻 | `last_run_end_at` | 完了・失敗時のみ表示 |
| 備考/エラー | `error_message` | `failed` の場合にエラー内容を表示 |

## 5 クエリ
```sql
select target_date,
  status,
  total_docs_count,
  target_docs_count,
  success_count ,
  last_run_start_at,
  last_run_end_at,
  error_message
  
  from import_daily_status
where 
    target_date >= '2026-04-01' and
    target_date <= '2026-04-30'
  order by target_date
;
```
