
# 🎨 Stock Whale Radar フロントエンド設計書 (Design.MD)

## 1. デザインコンセプト (Design Concept)
既存システム「KabuTrail」のモダン・クリーンなSaaSデザインを踏襲し、**「大量の開示データから、大口投資家の動向を瞬時に読み取れる」**視認性の高いダッシュボードを構築する。

*   **Data-Driven**: 数値（保有割合や増減）を主役にし、不要な装飾を削ぎ落とす。
*   **Glanceability (一瞥性)**: 赤（マイナス/減少）と緑・青（プラス/増加）のセマンティックカラーを効果的に使い、直感的な状況把握を促す。
*   **Responsive**: PCでの高密度なテーブル表示と、モバイルでのカード型タイムライン表示を両立させる。

## 2. カラースキーム & タイポグラフィ (Color & Typography)

KabuTrailのカラースキームを引き継ぎ、Tailwind CSS等のユーティリティクラスで管理する。

### Colors
*   **Primary (ブランドカラー)**: `Blue-600` 系（ボタン、アクティブなタブ、主要なリンク）
*   **Sidebar (ナビゲーション)**: `Slate-900` 系（ダークな背景色でメインエリアとの境界を明確に）
*   **Background**: `Gray-50` (メイン背景) / `White` (カード、テーブル背景)
*   **Semantic (意味的カラー)**:
    *   **Up / Increase**: `Red-500` 系（※日本の金融UIに合わせ、上昇・買い増しを赤または明るい朱色とする）
    *   **Down / Decrease**: `Green-500` または `Blue-500` 系（下落・売却）
    *   **New (新規取得)**: `Teal-500` または `Orange-500`（目立たせるアクセント）

### Typography
*   **Font Family**: `Inter`, `Noto Sans JP`, `Hiragino Sans`, `sans-serif`
*   数値を表示するカラムは、桁を揃えるため**等幅フォント（Monospace）**または `tabular-nums` を適用する。

## 3. 基本レイアウト構成 (Layout Structure)

*   **Left Sidebar (ナビゲーション)**
    *   ロゴ、主要ページへのリンク（ダッシュボード、銘柄検索、クジラ検索）。
    *   （管理者用）インポートステータス管理。
    *   レスポンシブ時（モバイル）はハンバーガーメニュー内に格納。
*   **Top Header (ヘッダー)**
    *   ユーザープロファイル、通知アイコン。
*   **Main Content (メインエリア)**
    *   カード（Card）コンポーネントをベースに情報をブロックごとに区切る。

## 4. 主要画面設計 (Key Screens)

KabuTrailの既存UIをどのようにStock Whale Radarにマッピングするかを定義します。

### 4.1 ダッシュボード (Home / Dashboard)
「今、市場で何が起きているか」をサマリー表示する画面。

*   **Top Cards (サマリー指標)**
    *   本日の報告書提出件数 / 新規登場したクジラ数 / 最も買われた銘柄 等を配置。
*   **タイムライン (Timeline View)**
    *   *流用元: KabuTrailの「監視メモ」のカードUI*
    *   最新の大量保有報告書を縦にスクロールできるタイムライン形式で表示。
    *   カード内情報: 時間、`[タグ: ファンド名]` ➔ `[銘柄名]`、保有割合の増減（例: `5.0% ➔ 6.2% (+1.2%)`）、保有目的の要約。
*   **急上昇ランキング (Hot Stocks)**
    *   *流用元: KabuTrailの「ダッシュボード右下の棒グラフ」または「テーブル」*
    *   直近で大口の買いが集中している銘柄のミニテーブル。

### 4.2 銘柄別詳細ページ (Stock Detail)
特定の企業について、大株主の状況を深掘りする画面。

*   **銘柄ヘッダー**
    *   *流用元: KabuTrailの「銘柄詳細情報」ヘッダー*
    *   銘柄名、コード、市場、現在の株価等の基本情報。
*   **大株主マトリクス (Table)**
    *   *流用元: KabuTrailの「保有銘柄一覧」テーブル*
    *   カラム: 提出者（ファンド名）、保有割合、前回比、報告義務発生日、保有目的。
    *   アクション: ファンド名をクリックで「クジラ別詳細ページ」へ遷移。
*   **株価 ✕ 報告書タイミングチャート (Chart)**
    *   *流用元: KabuTrailの「詳細ページのローソク足チャート」*
    *   株価チャート上に、**「いつ、誰が、大量保有報告書を出したか」を示すピン（アノテーション）**をプロットする。

### 4.3 クジラ（提出者）別詳細ページ (Whale Portfolio)
特定のアクティビストやファンドが、現在何を保有しているかを一覧化する画面。

*   **クジラヘッダー**
    *   ファンド名、所在地、代表者、EDINETコードなどの基本情報。
*   **保有ポートフォリオ (Table/Grid)**
    *   *流用元: KabuTrailの「バスケット」構成銘柄リスト*
    *   現在5%以上保有している銘柄のリスト。
    *   カラム: 銘柄名、保有割合、増減、株価（現在値）、評価額（※株価APIと連携できれば）。
*   **アクション履歴 (Timeline)**
    *   このファンドが過去に行った提出履歴（買い増し、処分など）の時系列リスト。

## 5. 共通UIコンポーネント (Reusable Components)

*   **Sparkline (ミニチャート)**
    *   テーブルの行内に配置し、過去数回の報告書における「保有割合の推移」を小さな折れ線グラフで表示。
*   **Status Badge (ステータスバッジ)**
    *   `新規取得` (Teal), `買い増し` (Red), `一部処分` (Blue), `5%未満消失` (Gray) など、アクションを一目で判別できるバッジ。
*   **Filter & Sort Toolbar (フィルターバー)**
    *   *流用元: KabuTrailのメモ一覧上部のフィルター*
    *   「保有割合5%以上のみ」「アクティビストのみ」などの絞り込み機能。

## 6. 推奨技術スタック (Frontend Tech Stack)

*   **Framework**: Next.js (App Router推奨)
*   **Styling**: Tailwind CSS
*   **UI Library**: `shadcn/ui` (KabuTrailのUIに近い、Radix UIベースのクリーンなコンポーネント群。カスタマイズ性が高く激しく推奨)
*   **Icons**: `Lucide React` 
*   **Data Fetching / State**: SWR または React Query (FastAPIからのデータ取得)
*   **Charts**: `Recharts` (シンプルなグラフ用) または `Lightweight Charts` (TradingView製。KabuTrailのような高度な株価チャート用)
